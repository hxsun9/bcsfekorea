# bcsfekorea – 냥코 대전쟁 세이브 에디터 한국어판

[BCSFE-Python](https://codeberg.org/fieryhenry/BCSFE-Python)(원작자: **fieryhenry**)을 한국어로 번역하고 쓰기 쉽게 다듬은 **비공식** 버전입니다.
무료 오픈소스이며 원본과 같은 GPL-3.0 라이선스를 따릅니다. 원본 설명은 [README_ORIGINAL_EN.md](README_ORIGINAL_EN.md)에 있습니다.

> ⚠️ **본인 책임하에 사용하세요.** 통조림·레어 티켓·플래티넘 티켓·레전드 티켓을 많이 넣으면 계정이 정지될 수 있습니다.
> 수정하기 전에 꼭 백업해 두세요. (에디터가 자동 백업도 만들어 둡니다.)
>
> 이 한국어판은 원작자와 관계가 없습니다. 이 버전에서 생긴 문제는 원작자가 아니라 이 저장소의 Issues에 남겨 주세요.

## 설치 & 실행

### PC (윈도우 / 맥 / 리눅스)

파이썬이 없다면 <https://www.python.org/downloads/> 에서 설치하세요. (윈도우는 설치 화면 아래 **"Add python.exe to PATH"** 를 꼭 체크)

```
python -m pip install bcsfekorea
```

그다음부터는 이것만 입력하면 됩니다.

```
python -m bcsfe
```

(`python -m bcsfekorea` 로 실행해도 똑같습니다.)

### 아이폰 / 아이패드 (a-Shell 앱)

1. App Store에서 **a-Shell**(무료)을 설치합니다.
2. a-Shell에서 한 번만 입력합니다.
   ```
   pip install bcsfekorea
   ```
3. 그다음부터는 이것만 입력하면 됩니다.
   ```
   python -m bcsfe
   ```

- 아이폰에는 파일 선택 창이 없어서 "tkinter를 찾을 수 없습니다" 안내가 나올 수 있습니다. 경로를 직접 입력하면 되고, `설정 변경` → `파일 선택 창 사용`을 끄면 더 이상 나오지 않습니다.

### 업데이트 / 원본 영어판과 같이 쓰기

- 업데이트: `python -m pip install --upgrade bcsfekorea` (에디터의 `업데이트 확인` 메뉴로도 됩니다)
- 원본 `bcsfe`와 같은 프로그램 폴더를 쓰기 때문에 **둘 중 하나만** 설치하세요. 원본이 깔려 있다면 먼저 `python -m pip uninstall bcsfe` 를 하세요.
- 설정과 백업은 원본과 같은 위치(윈도우: `문서\bcsfe`, a-Shell: `bcsfe` 폴더)에 저장됩니다. 예전에 영어로 쓰던 설정이 있어도 처음 한 번은 자동으로 한국어로 바뀝니다.

### 설치 없이 쓰기 (윈도우)

이 저장소를 내려받아(Code → Download ZIP) 압축을 풀고 **`에디터 실행.bat`** 을 더블클릭하세요. 필요한 라이브러리를 자동으로 설치하고, 설정·백업은 그 폴더 안의 `data` 폴더에 저장됩니다.

## 세이브 수정 순서 (기종 변경 코드 방식)

1. **게임에서** 설정 → **기종 변경**을 눌러 **인계 코드**와 **인증 번호**를 받습니다.
   (코드를 받은 뒤 그 기기에서 다시 플레이하면 코드가 무효가 됩니다.)
2. 에디터에서 **`1`** (기종 변경 코드로 세이브 다운로드)를 고릅니다.
3. 인계 코드, 인증 번호를 입력하고, 국가 코드는 **`kr`** (한국판)을 고릅니다.
4. 원하는 기능을 고릅니다.
   - 왼쪽 **번호**를 입력하거나
   - **단어로 검색**: `통조림`, `XP`, `레어 티켓`, `캐릭터`, `본능`, `보물`, `스토리` … (영어 이름도 됩니다: `cat food`, `talents`)
   - 그냥 엔터를 누르면 전체 목록이 나옵니다.
5. 다 고쳤으면 **`세이브 관리`** → **`세이브를 서버에 업로드하고 기종 변경 코드 받기`** 를 고릅니다.
6. 화면에 나온 **새 인계 코드 / 인증 번호**를 게임의 기종 변경 화면에 입력합니다.

## 입력 요령

| 상황 | 입력 방법 |
|---|---|
| 예 / 아니요 | `y` / `n` (한글 자판 상태의 `ㅛ`, 또는 `예`, `네`도 됩니다) |
| 여러 개 선택 | `1 2 3` (띄어쓰기), `1-10` (범위), `all` 또는 `전체` (모두) |
| 취소 / 나가기 | `q` (또는 `ㅂ`) |
| 캐릭터 레벨 | `50+70` (기본 50, 플러스 70), `max+max` (최대) |
| 무한 전투 아이템 | 분 단위 숫자, 또는 `infinity` / `무한` |

## 자주 묻는 질문

- **코드가 틀렸다고 나와요** → 국가 코드가 `kr`인지 확인하세요. 코드는 한 번 쓰면 다시 발급받아야 합니다.
- **"다른 기기에서 사용 중" 오류가 떠요** → `세이브 관리` → `계정 정지 해제 / "다른 기기에서 사용 중" 오류 해결`
- **영어로 바꾸고 싶어요** → `설정 변경` → `언어 (Language)` → `en`

## 원본과 달라진 점

- 화면의 모든 문구를 한국어로 번역 (`src/bcsfe/files/locales/ko`), 기본 언어 한국어
- 시작 화면을 줄이고 빠른 사용법 추가
- 기능 검색에서 한국어·영어 이름 모두 인식
- `y`/`q`/`all` 등을 한글 자판(`ㅛ`, `ㅂ`)이나 한국어(`예`, `전체`, `무한`)로 입력해도 인식
- PyPI 이름 `bcsfekorea`, 업데이트 확인도 `bcsfekorea` 기준
- 윈도우용 `에디터 실행.bat`(설치 없이 실행), `설치.bat`(이 폴더 내용으로 설치)

## 번역 수정 / 직접 빌드

번역은 AI(Claude)가 했습니다. 게임 공식 용어와 다른 표현이 있을 수 있습니다.
`src/bcsfe/files/locales/ko` 폴더의 `.properties` 파일을 고친 뒤:

```
python -m pip install .
python -m bcsfe --force-migrate
```
